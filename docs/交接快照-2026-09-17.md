## 4. 今日的关键结论：5 个真问题 + 两条结构性做法（**改这块前必读**）

### 4.1 输出侧：一次要「≥N 字」必被 `max_tokens` 截断

- 现象：要求「不少于 4000 字」→ 输出超 `max_tokens=8000` → `finish_reason=length` → 网关重试两次仍截断 → **422**（实测 92s）。
- 结论：**分段续写**。每段约 2200 字（提示词封顶与目标挂钩）、段数由目标算（`planFor`，1–5 段）、拼接达标；
  续写段注入**前文尾部 1400 字** +「不得重复／不要总结／不要在本段把整集收尾」。
- 实测产出：字段 5232～8925 字、一集 4054～6821 字。

### 4.2 输入侧：超长**不会失败**，但会贵/慢/「中间丢失」

- 实测（直打 DeepSeek）：**1 汉字 ≈ 1 token**；**30 万 token 输入不报错** → 上下文 ≥30 万，不用担心爆窗。
- 但六要素最大 8000×6 ≈ 4.8 万字，全量注入会让**每段都重送一遍**，且埋在中间的约束易被忽略（隐性质量下降）。
- 结论：`ScriptPrompts.context()` 统一组装 —— **目标字段全文 + 其它要素「头 60%+尾 40%」摘要（≤1200/项）+ 每集标题摘要全量 + 仅最近 2 集正文**，总量封顶 **12000 字**；
  被压缩/省略的项记 INFO 日志（不静默）。副带收益：8000 字目标的耗时从 135s 降到 96s。

### 4.3 模型会把 JSON 字符串写出真实换行

- 现象：`{"value":"第一段<真实换行>第二段"}` → `readTree` 报 `Unexpected character ('豪')…` → 两次尝试全废 → 422（内容其实是对的）。
- 结论：`JsonGuard.repairStrings()`，在网关**剥围栏后、校验前**只修字符串内裸控制字符；真结构损坏仍失败（不掩盖真问题）。8 个单测。

### 4.4 返回键名不能只认一个（且失败必须打日志）

- 现象：模型偶尔把正文放在 `text`/`body`/`value` 或子对象里；早期只读 `content` 得空串 → 抛 BizException 且**无任何日志**，排障只能猜。
- 结论：`pickText()` 多键回退（`content/value/text/body/paragraph/正文/内容`）→ 递归子对象 → 都找不到才失败，
  并打日志带**顶层字段名 + 原文开头 320 字**；提示词统一固定结构。

### 4.5 模型管不住长度（设 1500 字写出 2692）

- 三步处理：① 本段封顶与目标挂钩 `segmentCeiling = min(2600, max(800, 目标×1.3))`；
  ② 写超 **>1.5×** 时做**一次压缩重写**（明确保留人物/冲突/关键事件/**结尾钩子**），实测 **2692→1607**；
  **不做硬截**（硬截会把结尾钩子剪掉）；压缩失败保留原稿；无论成败都写进 `note`；
  ③ 单段分集的功能修正：`passes==1` 时不再是「起」而是「起→承转→合一次写完，必须在字数上限内收束」（这是超字主因）。

### 4.6 结构先行（B）与全剧记忆（C）

- **提纲先行**：先生成与段数 1:1 的提纲（每段 2–4 个子要点），再让每段「只写提纲第 K 条」→ 不跑偏、不重复、可展示；
  提纲生成失败**不阻断**正文。
- **提纲持久化（V18）**：`scripts.outlines`（要素→提纲）/ `script_episodes.outline`（本集提纲）。
  **复用判定 = 段数与本次目标一致且未要求刷新**（目标变了必须重生成）；弹窗可勾「重新生成写作提纲」。
- **全剧记忆**：「精简的故事」（≤1500 字，最高优先级）注入**所有**调用（字段/分集/一致性/引导），空则显式写「尚无」。

## 5. 工程纪律：今天新踩的坑（省下重复付学费）

1. **多编辑批量调用是「全部成功才生效」**：只要有一处 `oldText` 不匹配，**整批回滚**。
   今天因此漏改 `ScriptService.saveEpisode` 的提纲落库，直到验收才发现「分集提纲存不进去」。
   → **改多处时分批调用或逐条确认**，改完立刻编译 + 跑相关验收。
2. **`<script setup>` 里不能写 `export`**（SFC 编译器报错，而 `vue-tsc` 不报）：共享常量/工具要放 `utils/*.ts`。
3. **Java 注释里写 `\u00xx` 会编译失败**（注释同样处理 Unicode 转义）→ 写 `U+00xx` 或 `\\u00xx`。
4. **本机 GNU bash 里 python heredoc（`python3 - <<'PY'`）不执行**（静默 exit 49）→ 改脚本请**落盘 + scp**，别用 heredoc 传 python。
5. **清理脚本必须按 id 精确删**：今天库里已出现**用户自己建的剧本**（`宝马s1000rr`），
   冒烟脚本一律按 id 删、跑前先 `select` 确认；**永远不要按 title 模糊删**。
6. **前端发版前必跑** `npm run check:components`（模板用了但没 import 的组件只 warn 不报错）+ `type-check` + `build`；
   发完用「**线上产物里 grep 新文案**」确认新代码真的上线（今天用它验证了长度弹窗/提纲展示）。
7. **长 LLM 调用不要包在事务里**：只读路径不开事务（避免长时间占连接）；必须写库的（提纲持久化）采用
   「读上下文 → 调 LLM → 再写」的顺序。
8. **nginx 已放宽**：`/weaveora/api/` `proxy_read_timeout 1800s`（分段生成 1–3 分钟不会 504）。
