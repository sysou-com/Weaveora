## §7 关键结论沉淀（避免重复踩）

- **出图尺寸**：`ImageDims.of(画幅, 图片分辨率档)` = 以 **16:9 基准等比缩放** + 32 对齐；默认 1280 → 16:9 = 1280×704（=历史值）；**2560 档 → 2560×1408**（不是 1440，因为基础画幅是 1280×704）。
- **官方参数口径**：Wan2.2 未蒸馏 = `shift 5 / steps 40 / boundary 0.9 / guide_scale 3.5`；lightx2v 4 步蒸馏（`…260412`，**按 720p 训练**）为 **guidance-free（cfg 1.0）** → motion 档据此：cfg_low 1.0 + 高噪 cfg_high 1.5（高噪未蒸馏，需一点 CFG）。
- **hero 档"冲"的根因** = 低噪专家 4 步蒸馏 LoRA 在 3 步 regime 下过冲（333↔156/秒，2.4×）；**6 步零蒸馏会糊**（欠采样）。
- **画面"沸腾/多动症"**：主因是**内容/构图（脸太小、主体太多）+ 正词灌水**；参数层只占 ±13~33%（去"反静止"负向词 +3%、cfg2.0 −13%、hero +33%）；**补帧无关**。实测：第1镜（2 主体 / 脸 124px）背景 8/秒 vs 第4镜（3 主体 / 脸 72px）121/秒。
- **区域框（位置总控）**：**只影响关键帧出图**（视频通路完全不读）；h 越大出图越"特写"（实测 h0.5→0.98：脸占比 1.79%→2.48%、脸 72→83px）；**主体数是主因**（3 人 72px vs 2 人 124px）。
- **补帧**：整数倍 → RIFE（ComfyUI 内建 `FrameInterpolationModelLoader`+`FrameInterpolate`，盒子已有 `rife_v4.26/_heavy/film_net`）；非整数倍 → 原生 16fps + notes 提示；`minterpolate` 已禁用。
- **档位参数记忆**：`video_params.presetSnapshots`（切档自动存取，存 DB）。
- **出图"资源让出"**：出图任务曾固定 `need_vram_gb=31` → 每次卸载模型（**7 分钟里大半是重载**）→ S1 改为保留（keep_loaded）。
