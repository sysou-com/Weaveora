## 3. 出图档位（当前配置，配置页可改，代码不写死）

```
services.image = {
  engine: comfy,
  workflow:         /opt/weaveora/workflows/qwen_image_txt2img_film_api.json   (2512)
  img2imgWorkflow:  ""            ← 不用 img2img（会把定妆照白底带过来）
  editWorkflow:     /opt/weaveora/workflows/qwen_image_edit_api.json          (2511, 官方结构)
  steps: 20, cfg: 2.5, denoise: 1.0
}
```
- Edit 工作流是**官方结构**：`TextEncodeQwenImageEditPlus`（prompt+参考图同时输入）+ **主参考图 `VAEEncode` 作采样起点**；**不要加 resize 节点**（节点内部会把参考图缩到 ~1MP）。
- **不装 Lightning LoRA**（用户要求：不为速度牺牲细节）。
- 实测：1280×704 / 20 步 ≈ 采样 4.4 s/步；缓存策略 `--cache-ram 32`（曾用 `--cache-none` 导致每张重载 20G+CPU fp8 转换，已修）。

## 6. 重要纪律（血泪）

- **重启任何 GPU 服务必须走 `bash deploy/gpu2_restart.sh`**（先查库，有 queued/running 就拦；`FORCE=1` 才强推）。绝不在有任务时重启 —— 曾把用户 21:49 的对口型任务撞死（502 Cannot connect to host 127.0.0.1:8001）。
- **按 PID 精确杀**（`pkill -f` 会自匹配杀掉自己的 ssh）；用 `[x]` 防自匹配。
- spark 式排障顺序：先看 `/queue`（是否僵尸 prompt）→ 再看 worker 日志 → 再看 ComfyUI 日志（**过滤 `non matching host` 噪声**）。
- 交付一律给**可点开链接**（`web/_share/`）。
