cfg_high=3.5）。E.两个 umt5 不可互换：ComfyUI umt5_xxl_fp8_e4m3fn_scaled.safetensors（fp8+scale,412张量）vs talk t5_umt5-xxl-enc-bf16.pth（bf16,242张量，talk 必须 bf16）。F.部署坑：deploy/gpu2_first_image.py 要求 queue=0 且
