**操作方式（为什么要先摘软链）**：`/opt/weaveora/models/<x>` 下原本是指向 `/addDisk/...` 的**软链**；
若直接 `mv` 到该路径，`mv` 会**顺着软链写回数据盘**（白白拷一趟且看不出变化）。
所以：先 `rm` 软链 → 再 `mv` 真文件到该路径（ComfyUI 从同一目录名找到真文件，不需再建软链）。
`.done` 标记一并跟着真文件走（保持“标记与实体同目录”的约定）。

**回滚命令（原样可跑；把文件搬回数据盘并重建软链）**
