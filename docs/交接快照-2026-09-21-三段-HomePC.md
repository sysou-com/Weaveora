## 4. 坑（本会话新增，均已实测）

1. **PowerShell 5.1 按 ANSI/GBK 读 `.ps1`** → 脚本里写中文会让参数绑定失败（实测 `Register-ScheduledTask` 报 `RunLevel` 转换错，任务**静默不生效**）。本机 `.ps1` 一律**纯 ASCII** 或 UTF-8 **带 BOM**。
2. **睡眠判据**：`Kernel-Power 42/107` 秒级成对出现是噪声（进入睡眠过程的瞬时记录）；**权威口径 = `Microsoft-Windows-Power-Troubleshooter` Id=1** 里的「睡眠时间/唤醒时间/唤醒源」。
3. **`worker_nodes` 心跳 ≠ GPU 盒可达**：心跳来自 **VPS 上的 worker 进程**；判盒子只看 `/__edge/health` 200 + SSH 可连（host key 变化 = 实例重建）。
4. **成本公式 ≈ 上下文 × 请求数**（近二次放大）。两条主因：**长会话跨天/跨周复用**（对端 4 条异常会话 = 其 14 天的 89%，极端一条跨三周）与**大图进上下文**（本机单会话 16 张 37MB = 该会话 95% 体量，$3.93）。双机两周合计 ≈ **$27.6**。三纪律：阶段完成即快照+换会话 / 交接只传「路径+hash+3 行结论」/ 不往对话塞整图。
5. **日志「服务地址」会骗人**：`[comfy] 服务地址` 打的是 `services.lipsync.comfyUrl`，而出图/参考图上传走 `services.image.comfyUrl`（对端 §3.4）。
6. **`build/` 被 gitignore**（新增诊断脚本要 `git add -f`）；`deploy/` 不受影响。
