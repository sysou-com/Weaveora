## 4. 出图链路现状（结论优先）

### 4.1 引擎配置（DB 里当前生效，配置页可改，代码不写死）

```jsonc
services.image = {
  engine: "comfy",
  comfyUrl: "http://180.127.11.167:31058",
  workflow:        "/opt/weaveora/workflows/qwen_image_txt2img_film_api.json",  // 2512 文生图
  editWorkflow:    "/opt/weaveora/workflows/qwen_image_edit_api.json",          // 2511 参考图锚定
  img2imgWorkflow: null,                                                        // 故意留空（会把白底带过来）
  steps: 40, cfg: 4.0, denoise: 1.0
}
```

### 4.2 Edit 工作流接线（官方结构，勿打乱节点 id 顺序）

- `LoadImage` **3 个槽**：节点 `12`/`14`/`16` → 按 **id 字符串排序**依次喂 `image1/2/3`。
- `12 → ImageScale(目标尺寸, crop=disabled) → VAEEncode(节点 15) → KSampler.latent_image`（采样起点 = ref1 的 latent，`denoise=1.0`）。
- `TextEncodeQwenImageEditPlus`（正 `6` / 负 `7`）同时接 `vae + image1/image2/image3`。
- `ModelSamplingAuraFlow.shift = 3.1`（官方 2511 唯一参数差异）。
- worker 注入：`6.prompt / 7.prompt / 12.image / 14.image / 16.image / 13 尺寸 / 9.seed/steps/cfg/denoise`。

### 4.3 关键结论（都是实测/源码核对过的，别再重复踩）

1. **槽位命名要用模型自己的 `Picture N`**：`TextEncodeQwenImageEditPlus` 内部拼的是 `Picture 1: <|vision_start|>…`；只写 `image1` 时模型未必对得上 → 多主体张冠李戴。现在**两种并列写**：`Picture 1 (image1) = 宝玉[…]`。
2. **位置走「提示词」（路线 A）**。区域条件（`ConditioningSetAreaPercentage` 包参考图 conditioning）在 Edit 档会 `IndexError: tuple index out of range`，是 ComfyUI 核心限制，**不是接线错**；`WEAVEORA_IMAGE_AREA_COND=1` 才启用（默认 0）。
3. **Reference image 上传失败必须中止任务**：旧逻辑失败就跳过 → 后面的图前移一格而正词里的槽位号不变 → 角色脸互换。现在 `ComfyError` 直接失败并打印 `[comfy] 参考图槽位映射：Picture 1 = …`。
4. **Qwen-Image-Edit 对负词不敏感**（架构上没做 CFG 训练）：要"不要白底"就写"背景是…"，别堆负词。worker 仍会按语言追加白底/证件照类负词（代价低）。
5. **中英混排会两头听**：worker 会往正词前追加"怎么用参考图"的指令，现已**跟随提示词语言**（`_looks_zh()`，与后端 `isZhText` 同口径）。
6. **参考图 ≠ 锚定图**：上传素材图只作为"生成/指定定妆照"的输入；出图锚定**只认定妆照**（`subjects[].portraitAssetId`），没有定妆照的主体不注入（主主体缺则报错中止）。

### 4.4 ★ 出图正词的最终拼装顺序（改提示词前必看）

`still` / `clip`（Edit 档，有参考图）最终正词，从上到下：

| # | 片段 | 谁写的 |
|---|---|---|
| 1 | `参考图按送入顺序对应片中角色（Picture 1 Picture 2…）。… 场景：` / 英文同义句 | **worker**（`comfy_client.generate_via_workflow`，语言跟随） |
| 2 | 风格模板 prefix | `styledPositive()`（StyleTemplate） |
| 3 | `shot.positive_prompt` | LLM / 用户 |
| 4 | `Action: <shot.action>`（**仅 clip**） | `videoShotPayload()` |
| 5 | 身份约束句（每个角色只用自己的参考图，禁止混合/互换面容） | `refs.anchor()` = `refAnchor()` |
| 6 | `【设定年代/世界观】<era>…`（英文提示词则 `[Setting / era] …`） | **`JobService.applySetting()`**（P14，幂等） |
| 7 | `Picture N (imageN) = 主体[gender/age/build/look]（方位, x, y, 框 w×h）；… 【位置以本清单为准】` | **`JobService.applyLayoutRegions()`**（P13/P14） |

负词：`style.negative + shot.negative_prompt` →（clip 再加 `MOTION_NEGATIVE`）→ `applySetting` 的年代负词 → worker 的 Edit 档白底负词。

## 5. 数据模型速查（方案 JSON，`prompt_revisions.schema_json`）

```jsonc
{
  "mode": "video",
  "title": "…", "logline": "…",
  "setting": { "era": "清代 · 康熙年间", "notes": "服化道按清代贵族宅院形制" },   // ★ P14

  "subjects": [{
    "name": "宝玉", "kind": "person",            // person|vehicle|object|scene
    "aliases": ["贾宝玉", "宝二爷"],
    "enabled": true, "locked": false,
    "refs": [{ "assetId": "…", "checked": true, "region": {x,y,w,h} }],  // 素材图（只作定妆依据）
    "portraitAssetId": "…", "portraitVersion": 2,                        // 定妆照 = 唯一锚定物
    "region": { "x": 0.24, "y": 0.08, "w": 0.19, "h": 0.76 },            // 方案级默认位置
    "gender": "male", "age": "17", "height": "178cm",                    // ★ P14 人物档案
    "build": "清瘦", "personality": "多情敏感", "appearance": "大红箭袖，项上金螭璎珞"
  }],

  "shots": [{
    "shot_no": 4, "action": "…", "positive_prompt": "…", "negative_prompt": "…",
    "cast": ["宝玉", "可卿", "警幻"],              // 本镜主体；[] = 明确空镜；缺省 = 按文本自动
    "layout": [{ "subject": "宝玉", "x": 0.24, "y": 0.08, "w": 0.19, "h": 0.76 }],  // 镜级位置
    "keyframes": [{ "label": "结束帧", "composition": "…", "positive_prompt": "…",
                    "layout": [ … ] }],            // 帧级位置（优先级最高）
    "lipsync_targets": { "宝玉": { "x": 0.3, "y": 0.4 } }
  }]
}
```

**位置优先级**：`keyframes[j].layout`（帧） > `shots[].layout`（镜） > `subjects[].region`（方案默认） > `refs[].region` > `lipsync_targets` 点选（默认框 0.30×0.45）。
**归一化 0–1**；`w/h` 越大 = 越近越大；后端把结果写成 `referenceRegions`（与 `referenceKeys` 同序）**并**拼进正词。

## 9. 纪律与已踩的坑（浓缩，别重复付学费）

1. **重启 GPU 服务必须走 `bash deploy/gpu2_restart.sh`**（先查库：有 queued/running 就拦，`FORCE=1` 才强推）；**按 PID 精确杀**，`pkill -f` 会自匹配杀掉自己的 ssh（用 `[x]` 防匹配）。
2. **绝不在有任务时重启** API/worker/GPU 服务（曾把用户任务撞死，报 `502 Cannot connect to host 127.0.0.1:8001`）。
3. **不要静默降级/静默丢东西**：参考图失败要失败或明确告警；参考图多于槽位要告警；少槽位要摘空槽（不能"复用第一张"）。
4. **不要让 LLM 拥有用户数据**：`subjects[]`（定妆照/素材图/别名/档案）只能由用户与产品逻辑写；LLM 产出必须丢弃。
5. **不要两套方位并存**：位置只由用户在「位置总控」设定，并由系统作为最终裁定写进正词；LLM 文案禁写 left/right/foreground。
6. **中文人名的性别不是常识**：任何要画人的地方都必须显式给 `gender`（拿不准写 other，不能猜反）。
7. **排障顺序**：先看 `/queue`（僵尸 prompt）→ worker 日志 → ComfyUI 日志（过滤 `non matching host` 噪声）。
8. **交付一律给可点开链接**（`web/_share/` → `https://sysou.com/weaveora/_share/<file>`）。
9. 大文件下载走 `deploy/windows/gpu_model_downloader.js`（10 路 Range + 断点），禁止 `huggingface_hub` / 裸 curl（详见 `Weaveora.md §0.2`）。
