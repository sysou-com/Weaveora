## 1. 为什么不是 `pip install insightface`

本机只有 Python 3.13，`insightface` 无 cp313 wheel 且要在 Windows 上编 Cython（需 MSVC）。
所以本脚本**不依赖 insightface 包**，自己拼了同一条链（全部 onnxruntime + opencv）：

| 环节 | 本脚本 | 与 insightface 的关系 |
|---|---|---|
| 检脸 + 5 点 | `cv2.FaceDetectorYN`（YuNet, 232 KB） | 替代 SCRFD `det_10g`；landmark 顺序需重排 `[右,左,鼻,右嘴,左嘴] → [左,右,鼻,左嘴,右嘴]` |
| 对齐 | 自实现 `umeyama`（等价 `skimage.SimilarityTransform`）| 与 `face_align.estimate_norm` 等价（ArcFace 112 模板） |
| 识别 | `w600k_r50.onnx`（与 buffalo_l 同一份）| 同 |
| 换脸 | `inswapper_128.onnx` | `model_zoo/inswapper.py` **逐行照搬**（`emap`/latent 点乘/`paste_back` 混合） |

**唯一新增**：把 `cxy-2/Flux2-klein-9B-face-swapping-workflow`（2026-08-25 实读）指出的第 ① 条
（面部亮度/色相与身体不匹配 ⇒「假脸感」）做成了 `--no-brightness` 开关，默认开。

**残留问题（需用户肉眼定调）**：
1. **表情被洗平**：脸 #2 原本蹙眉（剧情是「急阻、惶急」），换脸后眉头松开 → inswapper 会把源脸的中性表情带进来；`--blend 0.8` 只缓解一点。
2. **皮肤偏光滑/年轻化**：128 模型的典型副作用（无 face-restore）。
3. **大侧脸最弱**：#1 宝玉是近侧脸，cos 0.639（三张里最低），侧脸本来就是换脸的弱项。
4. **它只解决「脸是谁」**：不解决身体/服装/站位/手势；若分镜本意是「宝玉背影不露脸」，那就不该给他换脸
   ⇒ **映射必须由分镜语义驱动，而不是「检出几张脸就换几张」**，否则会制造反向错误（把不该露的脸换成某人）。

## 7. 表情保真（第二轮，2026-09-26，用户裁定「先做 1」）

**问题**：inswapper 把源定妆照的中性表情带进来 → 可卿（本该蹙眉急阻）的眉间纹被抹平、嘴形变松。

**做法**（`--expr`）：只圈「**眉间 + 嘴**」两个椭圆的软遮罩（`--expr-region tight`，默认），遮罩内做**频带分离**：
低频（颜色/形状/身份）用换脸结果，**高频（皱纹/唇线/牙齿）用原图**，`--expr-freq σ` 是唯一旋钮：

```
out = blur(swap, σ) + (orig − blur(orig, σ))     # 仅在表情区内；区外仍是纯换脸
```

> ⚠️ **踩过的坑（已实测）**：第一版写成「`swap + (orig − blur(orig))`」——两套纹理叠加，结果高频**离原图更远**
> （keep_hf 跑成 **−0.01 / −0.42 / −1.29**，σ 越大越糟）。必须整块换频带，不是叠加。
> 另一个坑：第一版遮罩用了「眉带 + 眉间 + 嘴 + 法令纹」（`--expr-region wide`），面积过大 → 可卿 cos 从 0.81 掉到 0.58。

| 配置 | 宝玉 | 可卿 | 警幻 | 高频保留（代理） |
|---|---|---|---|---|
| 不做表情处理（基线） | **0.639** | **0.808** | **0.665** | 0 |
| tight + gain 闸门 + σ2 | 0.621 | 0.695 | 0.634 | 0.36 / 0.28 / 0.40 |
| tight + gain 闸门 + σ4 | 0.607 | 0.581 | 0.603 | 0.14 / 0.15 / 0.35 |
| **tight + 无闸门 + σ2** | 0.613 | 0.655 | 0.639 | 0.70 / 0.77 / 0.66 |
| **tight + 无闸门 + σ3（推荐）** | 0.598 | 0.620 | 0.628 | **0.79 / 0.83 / 0.73** |
| tight + 无闸门 + σ4 | 0.588 | 0.619 | 0.625 | 0.78 / 0.84 / 0.76 |
| wide + 无闸门 + σ4 | 0.527 | 0.516 | 0.551 | 0.79 / 0.86 / 0.79 |
| `--expr replace`（整块用原图） | 0.524 | 0.496 | 0.514 | 0.86 / 0.97 / 0.92 |

**推荐**：`--expr restore --expr-freq 3 --no-gate`（三张脸 cos 0.598/0.620/0.628 **仍全部 >0.5**，表情明显回来）；
保守要更多身份余量就用 σ2。`replace` **否掉**：嘴部出现两层结构、cos 掉到 0.50。

**视觉判定**：`out/cmp_face2_expr.png`（4 联：原图 / 仅换脸 / +表情恢复 / +replace）；
`out/ng_3/03_faces_zoom.png`（推荐配置下三张脸 4× 放大 before|after）。

> 「高频保留」是**自造的代理指标**（表情区里 `|hp|` 差值相对纯换脸的恢复比例），只用于横向比配置，
> 不等于表情保真度；最终由肉眼在 `cmp_face2_expr.png` 上定调。
