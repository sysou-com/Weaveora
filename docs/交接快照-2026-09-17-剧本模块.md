```bash

# ③ 既有功能未被影响（回归三处改动）
```

## 5. 已知取舍与后续可选项

1. **剧本卡是文本卡**：剧本没有图片资产，精选只展示 `condensedStory`/`story` 摘要（120 字），
   不像项目那样有预览图；若产品要「封面」，需另做上传/生成入口。
2. **一致性改写是一次 LLM 调用改写多集**（`apply-sync`），集数与正文过长时可能被 `max_tokens=8000` 截断
   → 建议一次勾选 ≤3 集；若截断会走 `DIRECTOR_PARSE_FAILED` 友好报错。
3. **`episode_no` 硬删除 + 重排**：删中间集会顺移后面的集号（已在 UI 二次确认里说明）。
4. **AI 更新字段读正文节选**：每集注入上限 1500 字（`ScriptPrompts.CONTEXT_EPISODE_CHARS`），集数很多时可调。
5. **分页文本域的取舍**：按「每页行数 × 全角字符宽度」估算，不读 DOM 换行（IME 安全）。
   中文内容恰好 15/25 行；英文/数字偏多时行数只会更少（不会溢出）；全角字符极少的情况不可逆（如超宽字母）。
   未做单元测试（web 仓无测试基建），核心分页函数已用 Node 脚本覆盖：空值/单行/恰好 15 行/16 行/超长单行硬切/
   段落混排/空行/25 行抽屉 —— 均无溢出、无损、连续。
6. **未做的 P2+**：剧本要素版本历史、集的历史版本回滚、剧本封面、剧本→多集批量转项目、发布到集市时的素材打包。
