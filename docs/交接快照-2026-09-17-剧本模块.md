## 2. 上线后暴露的 3 个坑（已修；改这块先读）

1. **一次要「≥4000 字」必被 `max_tokens=8000` 截断**（`finish_reason=length` → 网关重试两次 → 422，实测 92s）。
   已改为**分段续写**：每段约 2200 字、提示词硬上限 2600、最多 3 段，拼接后达标；续写段注入**前文尾部 1400 字** +
   「不得重复」+「不要总结」+「不要在本段把整集收尾」。常规两段（≈4400 字）即满足 ≥4000。
   - 代价：字段约 90～135s、一集约 90s → 前端已提示「1–2 分钟请勿关页」；「一键生成全部」改**并发 3 路**（串行要十几分钟）。
   - nginx `/weaveora/api/` 已是 `proxy_read_timeout 1800s`，无需改。
2. **模型把 JSON 字符串写出真实换行** → `readTree` 报 `Unexpected character ('豪'): was expecting comma…` → 两次尝试全废。
   已在网关（剥围栏后、校验前）加 `infra/llm/JsonGuard.repairStrings()` 修复字符串内裸控制字符；
   真结构损坏（少括号）仍会失败，不掩盖真问题。单测 `JsonGuardTest` 8 例。
3. **返回键名不能只认一个**：模型偶尔把正文放在 `text`/`body`/`value` 或子对象里；早期只读 `content` 得空串 →
   抛 BizException 且**无任何日志**（排障只能猜）。已加 `ScriptAiService.pickText()` 多键回退（含 `正文/内容`）+
   失败日志带**顶层字段名 + 原文开头 320 字**；提示词也统一成固定结构（每段都返回 title/summary/content）。

另配套韧性：**某段失败/返回空正文时不丢已生成部分** —— `retryBlank()` 先明确要求「必须给正文」重试一次，
仍失败则保留已有内容并在结果 `note` 里如实告知「未达 4000 字，可重试或手写补全」（不静默）。
