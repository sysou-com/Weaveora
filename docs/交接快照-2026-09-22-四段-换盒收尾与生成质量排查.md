## 5. 坑（本段新增，均已实测）

1. **SSH 探活必须带 `-i ~/.ssh/gpu_server_ed25519`**：本机**没有默认身份文件** ⇒ 不带 `-i` 会 `Permission denied (publickey)`。我据此**误判「公钥没装」**（实际一直好的，用户指出后才纠正）。**结论前先确认自己用对了凭据。**
2. **`ProtectSystem=full` 让 `/etc` 对 API 进程只读** ⇒ `Files.isWritable()` 恒 false ⇒ 页面必报「本机没有可写的 worker env」。修法必须白名单**目录**（原子写要在目录里建 tmp）；只白名单**文件**不够。**该 unit 不在仓库**，VPS 重建会丢。
3. **白名单漏键 = 整条配置链静默失效**：API 写进去了、日志不报错、下发档位里就是没有那个键（`resolution` 就是这么丢的）。**新增配置项时，务必同时改 API 与 worker 的接收白名单。**
4. **480p 是 A14B 的甜点**：V16 注释实测 1280×704/48 帧 >600 s、47.4/47.4 满载；832×480 只需 27~50 s。
5. **`/system_stats` 的 `torch_vram_*` 会误导**：实测 `get_device_properties().total_memory = 47.4 GiB` 正常，但 `torch_vram_total` 报 27~30 GiB ⇒ 判显存用 `nvidia-smi` + `mem_get_info()`。
6. **与对端 agent-network 的长消息来回 = 双向上下文放大**（每条长消息把两边整段上下文各重发一次）⇒ 用户已叫停同步；交接只传「路径 + hash + 3 行结论」。
7. **本机网络**：GitHub / HuggingFace 直连**不通**（`000`）→ **借 GPU 盒当出口**（`ssh gpu 'curl …'`）可达 `api.github.com`；**ModelScope 本机可直连**（阿里官方源，**优先用它**）；`hf-mirror.com` 可用但属**第三方通道**（引用须标注）。
8. **本地构建必须指定 JDK21**：`JAVA_HOME` 默认 `D:\Java\jdk-17`；`deploy/api-deploy.sh` 注释称 `/d/jdk21/jdk-21.0.2` 已不存在 —— **实际存在**（脚本自动探测能用）。手工构建：`export JAVA_HOME='D:\jdk21\jdk-21.0.2'`。
9. **同机双会话**：本机（`WIN-20240101MQK`）另有 pi 会话 ⇒ `~/.ssh/config`、`known_hosts`、DB/env **只能一个人写**（本段约定 writer = 本会话）。
10. **别把「端口能连」当「是我们的盒子」**：同一 IP 后面可能挂着不同主机（`.169` 的 `27412` 与 `15216` 主机键不同）；身份只能由**登录串 + argv[0]/权重清单**双重确认。
