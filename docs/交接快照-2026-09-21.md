## 7. 今天踩到的坑（照着避）

| 坑 | 事实/做法 |
|---|---|
| **ComfyUI `/interrupt` 会杀掉"当前正在跑"的任务**（不区分是谁提交的） | 生产任务与诊断任务共用同一队列：你在页面取消任务时，可能把我正在跑的实验杀掉（实测命中过一次 `execution_interrupted`）；反过来我的诊断任务也会排在你的生成后面 |
| 内存从 62 G 掉到 47 G（平台换实例） | 47 G 下 **talk（29.4G 子进程）+ 出图（26.75G 权重）无法共存**；`services_up.sh` 里 `--cache-ram 8 / smart memory` 的注释写的是"为 62G 机器调的"，换规格要重定 |
| 出图自动放大把 Qwen 挤出显存 | 冒烟后 VRAM 从 28.9 G → 5.1 G；同批连续出图会更划算，或考虑把放大挪到批次末尾 |
| 脸部贴回"半明半暗" | 羽化椭圆 + denoise 0.4–0.6 的接缝 ⇒ 暂不用该方案 |
| 端口/密钥 | `21282`(HTTP) / `21228`(SSH)；`~/.ssh/config` 三个别名已改；DB + VPS env 已同步（**平台配置页保存后仍要回读**，它会写回旧快照） |
