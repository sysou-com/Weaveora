# 出图正词模板（关键帧 / 静帧 / 定妆照）

> 口径来源（2026-09-22 核查，均为官方一手源）：
> - 阿里云百炼《图像编辑-千问》官方文档：`messages` = **1–3 张图 + 一条编辑指令**；多图时按**数组顺序**定义编号，
>   提示词里的「图1/图2/图3」必须与数组顺序一一对应；建议图片宽高在 384–3072 之间；
>   多图编辑默认输出总像素接近 `1024×1024`。
> - 官方 Prompt 建议（同上 / Qwen 社区官方答复）：「保持简短、避免冗余、用短句并以逗号分号分隔语义单元；
>   对复杂或可能互相冲突的编辑，**拆成多步**而不是在一条提示词里同时下达很多指令」。
> - ComfyUI 官方 Qwen-Image-Edit 教程：把输入缩放到约 1MP（100 万像素）以避免输入过大导致的画质损失。
> - Wan 官方《文生视频/图生视频 Prompt 指南》：进阶公式 = `主体（描述）+ 场景（描述）+ 运动（描述）+ 美学控制 + 风格化`；
>   其中**美学控制**含光源、光线环境、景别、视角、镜头、运镜；**景别**词典含：干净的单人镜头 / 双人镜头 / 群像镜头 / 定场镜头。

## 要求（按优先级）

1. **编号必须与送入顺序一致**：中文写「图1/图2/图3」，英文写 `Image 1` / `Image 2` / `Image 3`
   （英文字母与数字间有空格、首字母大写）。**只用一种编号写法** —— 不要同时出现 `image1` 与「图1」两套。
2. **只写一条编辑指令、一句自然语言**：短句，逗号/分号分隔语义单元；同一件事只说一次，不要用多种说法重复强调。
3. **必须写清**：场景与环境、机位与景别（近景/中景/全景、平拍/俯拍/仰拍）、光线与色调、氛围、主体在画面内的相对位置与相互动作关系。
4. **禁止写外观细节**（面容、五官、脸型、发型、服饰、体态、身高、年龄性别）—— 这些一律由参考图（定妆照）决定；
   文字再写一遍会与参考图抢话语权，实测会把角色改成文字描述的样子。
5. **禁止写坐标/框/像素/百分比**（`x=0.17`、`0.34–0.67`、`占画面高度 60%`）。位置只用自然语言的关系词：
   左/中/右、前景/后景、前后遮挡、位于…旁边、面向…。
6. **禁止在同一句里给出互相冲突的约束**（例：既要求「以某张图为最高依据」又要求「按文字重排站位/改身高」）。
   确有冲突时**先拆成多步**（先定场景与构图 → 再补人物关系），不要塞进一条提示词。
7. **负词只写必要项**：Qwen-Image-Edit 对负词不敏感（官方示例的负词就是一个空格）→ 靠**正向描述**塑景，不靠负词排除。
8. **语言**：本模板只约束**写法**，不改变输出语言 —— `lang=en` 时正/负词全英文、术语用英文
   （`left/center/right`、`close-up/medium shot`、`golden hour`、`double portrait`、`group shot`）；
   `lang=zh` 时全中文。
