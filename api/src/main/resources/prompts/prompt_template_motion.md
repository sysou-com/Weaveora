# 图生视频正词模板（clip / motion）

> 口径来源（2026-09-22 核查，官方一手源）：阿里云百炼官方《文生视频/图生视频 Prompt 指南》逐字口径 ——

**图生视频公式：提示词 = 运动 + 运镜**
> 「图像已经确定了主体、场景与风格，因此提示词**主要描述动态过程及运镜需求**。」
> - **运动描述**：结合图像中的元素（如人物、动物），描述其动态的过程（奔跑、打招呼），
>   可通过形容词控制动态的程度与速度（「快速地」「缓慢地」）。
> - **运镜**：对镜头运动有特定要求时写「镜头推进」「镜头左移」；**希望镜头不要变化，就写「固定镜头」强调**。
> - 官方镜头语言词典（可选用）：双人镜头、群像镜头、定场镜头；环绕运镜、复合运镜。

## 要求（按优先级）

1. **只写两件事：运动 + 运镜**。**不要**重复主体外观、人物档案、服装、年龄性别、场景、背景、道具、静态构图
   —— 这些已由首帧（关键帧）确定，再写一遍只会与首帧抢话语权（实测表现：面部/体态被重设、越走越近）。
2. **运动**：谁 + **正在进行**的动作（持续态/现在分词）+ 幅度与速率副词（缓慢地、轻微地、猛地、快速地）。
   写「过程」不写「结果」。
3. **次级运动**：至少 1 项 —— 衣摆/袖口/发丝/裙裾/水花/尘埃/烟雾/光影的随动。
4. **表情与眼神**：写清表情或眼神方向的变化（眼神转向、眼眶泛红、眉头紧锁、嘴角上扬）。
5. **运镜**：明确写镜头 —— 固定镜头 / 镜头缓慢推进 / 镜头拉远 / 镜头左移 / 镜头跟随 / 环绕运镜。
   没有明确要求时写「固定镜头」。
6. **动作密度**：一镜**一个主运动** + 最多两个次级运动；动作量与镜头时长匹配（时长越短，动作越少）。
   动作过多会被模型压缩到同一段时间里 → 观感「加速/变形」。
7. **禁止**：复述外观/档案/静态构图；写画面坐标与框；堆叠多条否定式禁令（**一条正向目标优于三条「禁止…」**）。
8. **语言**：本模板只约束**写法**，不改变输出语言 —— `lang=en` 时用英文（`camera pushes in slowly`、`static camera`、
   `turns to look right`、`robe and hair drift`）；`lang=zh` 时全中文。
